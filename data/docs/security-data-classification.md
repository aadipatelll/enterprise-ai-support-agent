# Data Classification Policy

Owner: Security Team · Applies to: all company data in any format

## Classification Levels

Corvane Labs uses four levels. Public data is approved for anyone, such as marketing pages. Internal data is for employees only, such as the org chart and internal wiki. Confidential data could harm the company if exposed, such as contracts, financial results, and source code. Restricted data is the most sensitive and includes customer personal data, payment data, credentials, and employee health or salary records.

## Handling Rules

Confidential data may be shared with vendors only under a signed NDA. Restricted data must be stored only in approved systems listed in the security wiki, must never be pasted into Slack or email, and must never be entered into external AI tools. Restricted data on laptops must stay inside encrypted, managed folders.

## Labeling

Google Docs containing Confidential or Restricted data must use the matching label from the Drive labels menu. Unlabeled documents are treated as Internal.

## Questions

If you are unsure how to classify data, treat it as Restricted until the Security team confirms otherwise. Ask in the #security-help Slack channel.
