# Software Installation

Owner: IT Department · Applies to: all company-managed devices

## Approved Software Catalog

Pre-approved applications such as Zoom, Slack, Visual Studio Code, Docker Desktop, Figma, and Postman can be installed at any time from the Self Service app on macOS or the Company Portal on Windows. These installs do not require a ticket or administrator rights.

## Requesting New Software

Software that is not in the catalog must be requested through an IT service desk ticket. Include the product name, a link to the vendor, the business reason, and whether the tool will process customer data. Security reviews new requests within five business days. Paid software also requires approval from your manager and a cost center code.

## Browser Extensions

Only extensions on the approved list may be installed in Chrome. The list includes 1Password, Grammarly Business, and the React Developer Tools. Unapproved extensions are removed automatically every night by the device management system.

## Administrator Rights

Standard employees do not have local administrator rights. Engineers can request temporary admin rights for up to 4 hours through the Privileges app, and every elevation is logged for audit.
