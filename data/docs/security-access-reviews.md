# Access Requests and Reviews

Owner: Security Team · Applies to: all employees and system owners

## Requesting Access

Request access to applications through the Access Request form in the IT portal. Each request needs approval from your manager and the system owner. Access to production systems also requires completing the production access training. Standard requests are fulfilled within two business days.

## Least Privilege

Grant only the minimum access needed to do the job. Production database write access is limited to on-call engineers and expires automatically after 8 hours. Administrator roles in Google Workspace, Okta, and AWS require a hardware security key.

## Quarterly Reviews

System owners review all user access every quarter, in January, April, July, and October. Reviewers must certify or revoke each account within 14 days of the review starting. Unreviewed access is revoked automatically at the end of the review period.

## Role Changes and Departures

When an employee changes teams, access from the old role is removed within 5 business days. When an employee leaves, all access is disabled within 1 hour of their departure time by the identity system.
